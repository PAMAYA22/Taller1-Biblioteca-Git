# Sistema de Gestión de Biblioteca

Taller 1 - Programación de Computadores III - UPC

## Autor

Pablo Andres Amaya Pabon - [1066281972]

## Descripción

Aplicación de consola desarrollada en Java para gestionar clientes,
libros y préstamos de una biblioteca.

La información se almacena temporalmente en memoria mediante ArrayList.

## Cómo ejecutar

1. Abrir el proyecto en IntelliJ IDEA.
2. Compilar el proyecto con Maven.
3. Ejecutar la clase Main.java.
4. Utilizar el menú de consola.

## Funcionalidades

- CRUD de clientes.
- CRUD de libros.
- Registro de préstamos.
- Registro de devoluciones.
- Listado de préstamos.
- Control de disponibilidad de libros.
